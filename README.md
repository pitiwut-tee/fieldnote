# สมุดคาถา

ระบบฝึกวิทย์-คณิตรายวันสำหรับเตรียมสอบเข้า ม.4 โรงเรียนวิทยาศาสตร์

- `index.html` หน้าของนักเรียน (GitHub Pages) ผลฝึกเก็บในเบราว์เซอร์ ส่งให้ผู้ปกครองด้วยรหัสทาง LINE
- `src/app.html` ตัวแอป · `content/` เนื้อหา (ชุดฝึก ด่านสำรวจ คำศัพท์ บทอ่าน ปฏิทิน) · `tools/` build และตรวจ
- สร้างหน้า: `python3 tools/build.py` · ตรวจ: `node tools/verify.js`
- งานเพิ่มเนื้อหาอัตโนมัติทุกพุธและอาทิตย์: ดู `AUTOMATION.md`
